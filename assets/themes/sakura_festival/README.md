# Sakura Festival Theme Assets

Place optional PNG sprite overrides in this folder:
- `sakura.png`
- `lantern.png`
- `onigiri.png`
- `dango.png`
- `fox_mask.png`
- `background.png`

If any file is omitted, the game automatically renders its code-drawn vector art with soft outlines, glossy highlights, and cute anime eyes.
